# Stoic 30 — 個人版 V2

手機優先、單人使用、不需登入的 30 天斯多葛安全感練習網站。

## V2 完善內容
- 今日頁依時間顯示早晨 / 晚間提示
- 早晨控制二分法與晚間回顧
- 90 秒焦慮介入流程
- 延遲確認可跨關頁 / 重開後繼續
- 本週 vs 上週：焦慮、仍去確認、延遲成功率、平均恢復時間
- 最近 7 天恢復時間圖
- 30 天每日完成狀態（完整 / 部分）
- 焦慮紀錄可查看、修改、刪除
- 設定 30 天開始日
- JSON 完整備份與還原
- CSV 匯出
- 自動讀取 V1 localStorage 資料並升級到 V2
- PWA / 加入手機主畫面

## 隱私
資料預設只存在目前瀏覽器 localStorage，不會上傳到伺服器。清除瀏覽器網站資料會刪除紀錄，建議定期匯出 JSON 備份。

## GitHub Pages
此專案使用 GitHub Actions 部署到 GitHub Pages。
